# tigov.github.io

A small test website (a fictional bike repair shop) used to test SEO tools against a real, public site:
Search Console, Google Analytics, PageSpeed Insights and site crawlers.

It has a few SEO problems on purpose, so there is something to find:
- the About page has no description, a vague title and a link to a page that doesn't exist
- the Contact page is missing from the sitemap
- an image on the Services page has no alt text

Published by GitHub Pages at https://tigov.github.io/.
